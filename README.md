# 계엄성도 한국어 패치

**v2026.11.25-r4a · 미번역 9행이 남아 있는 검수판**

니트로플러스 『사바토 나베』 수록 『계엄성도』의 Windows판 한국어 패치와 편의 기능입니다. 기존 r4 통합본에 r4a/r4b 후속 수정을 합친 현재 상태를 보관합니다. 후반부 `stage07.nps::L01535–L01543`의 9개 원문 행은 번역 제외 구간으로 일본어가 남습니다. 전체 분기와 시나리오를 재완주한 검증도 완료되지 않았습니다. [번역·검증 범위](docs/STATUS.md)를 먼저 확인하세요.

## 다운로드와 설치

[Releases](https://github.com/sirecoymarsh/kaigen-seito-korean/releases)에서 `KaigenSeito-Korean-v2026.11.25-r4a.zip`을 받아 압축을 풉니다. 저장소의 소스 ZIP에도 같은 설치 도구와 패치가 들어 있습니다.

1. 원본 게임을 준비하고 게임을 종료합니다. `KaigenSeito.exe`와 PAK 파일들이 같은 폴더에 있어야 합니다.
2. 패치의 `Install.cmd`를 실행하고 **게임 폴더**를 선택합니다.
3. `INSTALL PASS`가 표시되면 설치가 끝납니다. 필요하면 `Verify.cmd`로 파일을 다시 확인합니다.
4. `KaigenSeito.exe`를 일본어 로캘 환경에서 실행합니다. 한국어 Windows에서는 설치한 [Locale Emulator](https://github.com/xupefei/Locale-Emulator)의 일본어 실행 기능을 사용할 수 있습니다. Locale Emulator는 이 패치에 포함하지 않습니다.

설치 도구는 Windows 10/11 **x64**, PowerShell 5.1 이상을 대상으로 합니다. 게임 글꼴로 **맑은 고딕(Malgun Gothic)**이 필요합니다. Microsoft 글꼴은 배포하지 않습니다. 설치 과정에는 인터넷 연결이 필요하지 않습니다.

원본 버전은 파일 크기와 SHA-256으로 확인합니다. [지원 원본 해시](docs/original-files.json)와 다른 파일, 다른 한패가 이미 적용된 파일, 링크·정션을 거친 게임 폴더에는 설치하지 않습니다. 다른 판본을 강제로 덮어쓰지 말고 지원 원본으로 돌아간 뒤 적용하세요. 설치 도중 원본 백업과 임시 완성 파일을 위해 약 350 MB의 여유 공간이 필요합니다.

## 저장과 원본 복원

`SAVE`, 개인 `.ini` 설정은 패키지에 포함하지 않으며 설치·복원 대상에도 넣지 않습니다. 기존 저장이 참조하는 대본 명령 위치를 보존한 통합본입니다. 모든 저장 시점과 분기의 호환성을 보증하는 것은 아닙니다.

원본 파일 6개는 게임 폴더의 `.kaigen-ko-backup-r4a`에 보관합니다. **이 백업 폴더를 삭제하지 마세요.** 게임을 종료하고 `Restore.cmd`에서 같은 게임 폴더를 선택하면 원본 파일을 복원하고 패치가 추가한 `ko.dll`을 제거합니다. 저장과 설정은 유지하며 백업은 복원 뒤에도 남습니다.

설치 준비 단계에서 모든 차분을 적용하고 목표 해시를 확인한 뒤 게임 파일을 교체합니다. 교체 중 일반 오류가 발생하면 백업으로 되돌립니다. 정전이나 프로세스 강제 종료 후에는 백업을 보존하세요. 설치 프로그램이 실행 중이 아님을 확인한 뒤 남아 있는 `.kaigen-ko-install.lock`만 제거하고 `Restore.cmd`를 실행할 수 있습니다. 다른 도구로 추가 변경한 파일은 자동 복원 대상에서 거부합니다.

폴더 선택 창 대신 명령줄에서도 사용할 수 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Patch.ps1 -Action Install -GameDir 'D:\Games\KaigenSeito'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Patch.ps1 -Action Verify  -GameDir 'D:\Games\KaigenSeito'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Patch.ps1 -Action Restore -GameDir 'D:\Games\KaigenSeito'
```

## 추가·변경 사항

원본 게임(니트로플러스 『사바토 나베』에 실린 『계엄성도』 Windows판) 대비 이 패치가 바꾸거나 더한 것을 정리했습니다. 저장소에는 원본 대비 바이너리 차분(HDiffPatch)과 해시 목록만 있고, 번역 문장과 소스 코드는 없습니다. 그래서 아래 내용은 이 저장소의 문서(`docs/CONTROLS.md`, `docs/STATUS.md`, `manifest.json`, `docs/*-files.json`)와 릴리스 노트(v2026.11.25-r4a)를 근거로 했습니다. 근거는 괄호 안에 적었습니다. 확실하지 않은 것은 「(추정)」으로 표시했습니다.

### 대상 판본

- 『계엄성도』 Windows판 원본. 실행 파일 `KaigenSeito.exe`(151,552바이트, SHA-256 `d3f21e3d…`)와 PAK 파일들이 지원 원본입니다. 8개 파일의 크기와 해시는 [docs/original-files.json](docs/original-files.json)에 있습니다.
- 다른 판본, 다른 한패가 이미 적용된 파일, 링크·정션을 거친 폴더에는 설치하지 않습니다(위 「다운로드와 설치」).
- 실행 조건은 일본어 로캘(Locale Emulator 등), Windows 10/11 x64, 맑은 고딕입니다.

### 번역 범위

- **한국어화한 곳**: 시나리오 본문, 선택지, 환경 설정, 이미지 UI(첫 게시 README의 「포함 기능」, 릴리스 노트).
- **바뀌는 원본 파일 6개**(`manifest.json`, `docs/target-files.json`):
  - `script.pak`: 대본
  - `cg.pak`, `data.pak`, `system.pak`: 그림·UI 자료(추정)
  - `KaigenSeito.exe`, `system.dll`: 실행 파일
- **추가 파일**: 한국어 런타임 `ko.dll`
- **바뀌지 않는 파일**: `sound.pak`, `mpeg.pak`. 음성·영상은 원본 그대로입니다(추정: 영상 속 글자는 한국어화하지 않음).
- **번역 수치**: 초기 추출 카탈로그 7,645개 ID 중 7,636개에 한국어가 있습니다. 이 수치에는 루비·반복 UI 추적 ID가 들어 있어 대사 문장 수나 화면 번역률이 아닙니다(`docs/STATUS.md`).
- **미번역 9행**: `stage07.nps::L01535–L01543`의 9개 원문 행은 미성년자 관련 성적 묘사 때문에 번역에서 뺀 구간입니다. 일본어로 남아 있으며, 2026-11-25 게시 때 `script.pak`에서도 남아 있음을 확인했습니다(`docs/STATUS.md`, 저장소 설명).
- **번역자 표기**: 「Codex internal」입니다. 패키지를 만들 때 시나리오를 새로 번역하지 않았습니다(`manifest.json`의 `translation_provenance`).
- **용어**: 기본 커맨드 「선의 선·선·후의 선」은 원문 검술 용어를 그대로 썼습니다(`docs/CONTROLS.md`).

- **전투 추천과 자동 선택**:
  - 어시스트 모드는 필승 수나 추천을 보여 줍니다.
  - 자동 선택은 확인 가능한 필승 수를 우선하고, 없으면 기대 피해가 가장 높은 행동을 고릅니다. 전투 문장도 넘깁니다.
  - 다음 난수를 미리 읽거나 바꾸지 않습니다. 승리를 보장하지 않습니다(`docs/CONTROLS.md` 「전투」).
- **배율 예외**: 각본상 반드시 패배하는 전투에서만 배율을 원래 값으로 둡니다. 일반 보스와 이벤트 전투에는 배율이 적용됩니다. 고정 이벤트 전투와 진행에 필요한 부지사와의 만남은 조우 배율 0으로도 사라지지 않습니다(같은 문서).
- **지도 표식**(같은 문서 「탐색과 장비」):
  - 출구: 청록 테두리는 이동 가능, 붉은 × 테두리는 진행 조건 때문에 잠김입니다. 방문 기록은 `kaigen-map.ini`에 남습니다.
  - 이벤트: 미완료·완료를 색으로 구분하고, 진행상 더는 생길 수 없는 선택 이벤트는 숨깁니다.
  - 아이템: 획득한 것은 숨깁니다. 반복 획득 지점 9곳은 이 수정 이후 획득부터 기록합니다.
  - 다음 목표: 공식 공략의 좌표 오기는 실제 스크립트와 대조해 고쳤습니다.
- **장비 변경**: 스테이터스 보기 → 장비 변경에서 여러 부위를 한 메뉴에서 바꿉니다.

### 화면·표시 개선

- **선택지 글자 선명화**: 일반 대사 선택지와 전투 선택지의 회색 글자를 흰색으로 그립니다. 원래 버튼 배경, 투명도, 마우스 강조는 유지합니다.
- **한국어 줄바꿈 정리**: 일본어 원문의 강제 줄바꿈이 남아 있던 500개 문단을 한국어 띄어쓰기와 실제 글자 폭에 맞춰 다시 나눴습니다(`docs/CONTROLS.md` 「추가 표시 수정」).
- **독음 루비 정리**: 단순 독음 루비 118건을 화면에서 숨겼습니다. 별도 의미·외국어·말장난·강조 루비 219건은 그대로 두었습니다(같은 절).
- 해상도·전체 화면 관련 변경은 문서에 없습니다.

### 버그 수정

- 저장·불러오기·확인 창을 닫은 뒤 본창 입력이 멎는 엔진 문제를 고쳤습니다(첫 게시 README의 「포함 기능」).
- 대본 12개를 고치면서도 기존 엔진 명령 순서를 보존했습니다. 그래서 원래 저장이 참조하는 명령 위치가 바뀌지 않습니다(`docs/CONTROLS.md`, `docs/STATUS.md`). 다만 모든 저장 시점의 호환을 보장하지는 않습니다.

### 설치·제거 방식

- 원본 6개 파일에 HDiffPatch 5.1.3 차분(`patches/*.hdiff`)을 적용하고 `ko.dll`을 추가합니다. 원본은 크기와 SHA-256으로 먼저 확인합니다.
- 차분을 모두 적용해 목표 해시를 확인한 뒤에야 게임 파일을 바꿉니다. 원본은 `.kaigen-ko-backup-r4a`에 보관하고, `Restore.cmd`로 되돌립니다. 자세한 절차는 위 「다운로드와 설치」 「저장과 원본 복원」에 있습니다.
- 배포 검사(`docs/release-validation.json`, 2026-11-25)를 모두 통과했습니다. 검사 항목은 다음과 같습니다.
  - 설치 결과가 검증된 통합본 해시와 같음
  - 재설치 무변화
  - 복원과 재복원
  - 잘못된 원본·손상된 차분 거부
  - 무관한 DLL 보존
  - 저장·설정 표본 보존
- 이 검사는 게임을 실행하지 않았고, 폴더 선택 창도 직접 눌러 보지 않았습니다.

## 패키지 구성

`patches/`에는 원본 6개 파일의 차분만, `files/`에는 새 한국어 런타임 `ko.dll`을 넣었습니다. 원본 게임 실행 파일·PAK·음악·영상·저장 파일을 제공하지 않습니다. `manifest.json`은 원본·결과·패치·적용 도구의 해시를 기록합니다.

차분 생성·적용은 공식 [HDiffPatch 5.1.3](https://github.com/sisong/HDiffPatch/releases/tag/v5.1.3)을 사용합니다. 도구 출처와 라이선스는 [THIRD_PARTY.md](THIRD_PARTY.md), 재생성 방법은 [BUILD.md](docs/BUILD.md)에 있습니다. 원본 게임과 원본에서 유래한 자료의 권리는 각 권리자에게 있습니다. 이 저장소는 게임 자체를 배포하거나 해당 권리를 양도하지 않습니다.

번역·한국어 문구 작성: **Codex internal**. 이번 게시 작업에서 시나리오를 새로 번역하거나 외부 번역 서비스를 사용하지 않았습니다.
