# 번역 및 검증 범위

## 번역 범위

초기 추출 카탈로그 7,645개 ID 모두에 한국어 대상이 있습니다. r4a 까지 번역 제외였던 `stage07.nps::L01535–L01543` 9행은 r4b 에서 노골적 묘사 없는 회상 농담으로 담담하게 옮겼습니다.

## r4b 변경

- 검수 확정 수정 49건(오역·용어 불일치), 帝=황제·錦旗=비단 깃발·禁裏=황궁 통일.
- 클릭 대기(`<k>`) 뒤 문장이 붙어 나오던 81곳에 띄어쓰기.
- 게임 내장 C 런타임의 코드 페이지를 932 로 고정해 한국어 Windows 에서 Locale Emulator 없이 실행. 한글 경로 설치본에서 실행·세이브 기록 확인.
- `ko.dll` 에서 시험용 캡처 코드와 개발 PC 경로 제거, `system.dll` 판이 다르면 갈고리를 걸지 않음.
- 설치기: 이전 판에서 업그레이드, 한국어 안내 문구.

이 수치는 루비·반복 UI 추적 ID 등을 포함하므로 독립적인 대사 문장 수나 게임 전체 화면의 번역률로 해석하면 안 됩니다. 전체 분기 재완주와 모든 화면의 확인은 완료하지 않았습니다.

## 재사용한 통합본 검증

- 후속 변경 대본 12개의 기존 엔진 명령 순서를 보존한 것을 실제 엔진으로 확인.
- 일반 선택지, 전투 선택지, 한국어 본문 줄바꿈과 루비 화면 확인.
- 추천 계산 60개 상태 대조와 실제 전투 표시 확인.
- 실제 대본 지도 486칸·표식 67개 대조, 문 목적지 경로 891건 검사.
- 실제 엔진에서 문 클릭, 지도 진입 직후 이동 메뉴, 출구 재방문 질문 확인.
- 반드시 패배하는 전투만 배율 제외, 일반 보스에는 배율 유지 확인.
- 아이템 획득 기록이 소비 뒤에도 유지되는 것 확인.

r4b 에서는 숨은 화면에서 설치본을 띄워 타이틀·도입부·선택지·불러오기 창을 확인했고, 위의 나머지 게임 플레이 검사는 다시 하지 않았습니다. 배포 패치 적용 결과가 해당 검증을 거친 통합본의 9개 런타임 파일과 해시가 일치하는지 별도로 검사합니다. 검사 결과는 `release-validation.json`에 기록합니다.

## 알려진 제한

- 자동 전투와 추천은 승리 보장이 아닙니다. 표시 성공률은 개별 행동의 성공률이며 전투 전체 승률이 아닙니다.
- 반복 획득 지점 9곳의 과거 획득 이력은 원래 저장에 없으므로, 업데이트 이후 첫 획득부터 기록합니다.
- 이전 저장에 기록되지 않은 과거 출구 방문은 복원할 수 없습니다.
- 게임 안 문장 검색·편집 도구는 이번 버전에 포함하지 않았습니다.
- 모든 장면·분기·저장 시점의 호환성이나 화면 배치는 아직 확인하지 않았습니다.
