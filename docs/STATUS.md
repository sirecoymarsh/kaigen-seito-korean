# 번역 및 검증 범위

최신 배포판: **v2026.11.27-r5.3 누적 통합 설치판**. 게임 파일은 검증된 r5.2와 동일합니다. [직접 설치·업데이트 검사](cumulative-install-validation.json)와 [최종 DLL 실제 실행 검사](runtime-r5.2-verification.json)를 참조하세요. 기존 r5·r4a·r4b 검사 기록은 당시 판의 기록이며, 재사용 범위는 아래에 구분했습니다. 전체 분기 재완주 전의 **Pre-release**입니다.

## 번역·레이아웃

초기 카탈로그 7,645개 후보 ID 모두에 대상 한국어가 있으며, r4a에서 제외했던 9행은 r4b에서 반영했습니다. 이 숫자에는 반복 UI와 루비가 포함되므로 독립적인 대사 수나 게임 전체 화면 번역률이 아닙니다. r4b 검수 수정은 Claude, 이후 통합·표시 수리는 Codex가 수행했습니다.

현재 본문·백로그 정적 검사에서는 68개 대본의 8,740개 행을 측정했습니다. 236개 기존 동적 행은 실제 적 이름·긴 장비명 등을 대조했고 필요한 개행을 보완했습니다. 원래 이야기의 저장 위치에 영향을 주는 명령 배열을 보존했습니다. 새로 만든 회상 진입부 11곳은 이전 배경 노출을 막는 화면 확정 명령을 추가했으므로 모든 새 회상 대본의 명령 배열까지 동일하다는 주장은 하지 않습니다.

## 배포 검사와 실제 게임 검사 구분

- [누적 설치·업데이트·복원](cumulative-install-validation.json): 배포 차분을 원본 시험 사본에 적용해 최신 통합본 8개 결과 파일과 변하지 않는 sound.pak의 해시를 확인합니다. 반복 설치·복원, 잘못된 원본·손상 차분·알 수 없는 DLL 거부와 저장·설정 표본 보존을 검사합니다.
- [r4a 업데이트](upgrade-r4a-validation.json), [r4b 업데이트](upgrade-r4b-validation.json): 이전 검증 결과를 재사용합니다. 설치기 코드와 해당 구버전 파일 인식·원본 백업 처리는 동일합니다.
- [실제 엔진 검증 연결](runtime-verification.json): 동일한 최종 DLL의 오프닝·전투 후 미니맵·좌표 변환 검사를 재사용합니다. [r5 당시 기록](runtime-r5-verification.json)은 기록실과 기존 기능의 이력입니다.
- [PV 검사](video-verification.json): 9,633,133바이트, 640×480, 약 2분 2.7초. 기존 전체 디코드 통과 증거와 같은 해시의 완성 파일을 배포합니다.

배포 검사는 사용자 저장을 읽거나 게임을 실행하지 않습니다. 네이티브 검증은 별도 숨은 데스크톱 시험 사본에서 이루어졌습니다. 이번 패키징에서 게임 전체를 다시 플레이한 것은 아닙니다.

## r5 당시 실제 확인 범위

r5.1·r5.2에서 바뀐 기능의 최신 증거는 위 별도 기록을 따릅니다.

- 타이틀 ‘이어하기’: 저장 없음, 수동·빠른·자동 저장 각각의 최신 판별, 실제 불러오기와 복귀 후 입력.
- 기록실: 첫 선택 표시, 상단 탭 6회·왼쪽 구역 6회 전환, 휠 전환, CG 복귀, 음악 이동·정지·재생과 타이틀 복귀.
- 음악 목록 흰 번쩍임: 실제 창 표면 표본에서 최대 흰 영역이 수정 전 95.92%에서 수정 후 0.99% 미만으로 감소. 문자 등 정상 흰색도 포함한 값이며 모든 프레임의 지터가 0이라는 뜻은 아닙니다.
- 오프닝: 준비 중 검은 화면, 첫 ESC의 계속/스킵, 반복 ESC, 마우스 클릭 무시, 두 로고판의 기존 마지막 8초 표본 자연 종료. 기존 MPEG 완성본을 재인코딩하지 않았으며 최종판의 전체 길이를 이번에 다시 계측한 것은 아닙니다.
- 기존 재사용 범위: CG 9그룹·접근 가능한 차분 24개, 대표 긴 본문·시·루비와 하단 창, 회상 진입 배경, 어시스트 표시 분리, 사용자 지정 썸네일, 특수 전투 경고·버티기 턴·타이틀 보컬 자막 등.

## 남은 제한

- 전체 시나리오·모든 분기·모든 저장 지점을 재완주하지 않았습니다. 정적 폭 검사가 모든 동적 장면의 실제 렌더링을 대신하지 않습니다.
- 자동 선택과 추천은 승리 보장이 아닙니다. 개별 커맨드 확률과 전투 예상 승률도 구분해야 합니다.
- 원래 저장에 없던 과거 출구 방문과 반복 아이템 획득 이력은 완전히 복원할 수 없습니다. 해당 기록 기능 이후의 방문·획득을 사용합니다.
- 반드시 패배하는 전투의 배율 제외는 확인된 대상에 적용합니다. 모든 미확인 이벤트까지 일괄 안전성을 주장하지 않습니다.
- 추가 음악 `bgm20`~`bgm23`의 공식 곡명은 확정하지 못했습니다.
- 하나치라스 요약은 사용자 제공 초안에 사실관계 검수를 적용한 추가 콘텐츠이며 원작 공식 시나리오가 아닙니다.
- 게임 안 문장 검색·직접 편집 도구는 이번 패치에 포함하지 않았습니다.
- 설치·검사·복원의 명령줄 경로를 검증했습니다. 폴더 선택 대화창을 이번 배포에서 새로 수동 조작하지는 않았습니다.
- 최근 통합본의 사용자 직접 재확인은 별도입니다. 여기의 통과 표시는 수행한 검사 범위에 한정됩니다.
