# 번역 및 검증 범위

이 릴리스는 **미완성 검수판**입니다.

## 확인된 미번역

초기 추출 카탈로그 7,645개 ID 중 7,636개에 한국어 대상이 있고, `stage07.nps::L01535–L01543`의 9개 행은 번역 제외 구간으로 원문을 유지합니다. 미성년자 관련 성적 묘사 때문에 제외했던 구간이며, 원문·대사는 여기 싣지 않습니다. 2026-11-25 게시 준비 시 현재 통합본의 `script.pak`에서도 이 9개 원문이 남아 있음을 확인했습니다.

이 수치는 루비·반복 UI 추적 ID 등을 포함하므로 독립적인 대사 문장 수나 게임 전체 화면의 번역률로 해석하면 안 됩니다. 전체 분기 재완주와 모든 화면의 확인은 완료하지 않았습니다.

## 재사용한 통합본 검증

- 후속 변경 대본 12개의 기존 엔진 명령 순서를 보존한 것을 실제 엔진으로 확인.
- 일반 선택지, 전투 선택지, 한국어 본문 줄바꿈과 루비 화면 확인.
- 추천 계산 60개 상태 대조와 실제 전투 표시 확인.
- 실제 대본 지도 486칸·표식 67개 대조, 문 목적지 경로 891건 검사.
- 실제 엔진에서 문 클릭, 지도 진입 직후 이동 메뉴, 출구 재방문 질문 확인.
- 반드시 패배하는 전투만 배율 제외, 일반 보스에는 배율 유지 확인.
- 아이템 획득 기록이 소비 뒤에도 유지되는 것 확인.

이번 게시 작업에서 위 게임 플레이 검사를 다시 수행한 것은 아닙니다. 배포 패치 적용 결과가 해당 검증을 거친 통합본의 9개 런타임 파일과 해시가 일치하는지 별도로 검사합니다. 검사 결과는 `release-validation.json`에 기록합니다.
