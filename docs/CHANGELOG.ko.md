# 계엄성도 한국어 패치 전체 수정 사항

## v2026.11.27-r5.1 · 소형 업데이트

- 도쿄 부지사에게 항복해야 진행되는 조건에서 자동 선택이 원래 항복 분기로 이어지도록 수정.
- 원본 엔진의 시스템 메뉴 삭제로 실제 창 테두리 드래그·최대화가 막히던 문제 수정.
- r5 대상 `ko.dll` 차분만 제공. 대본·영상·그래픽·저장·설정은 불변. [설치와 검증](HOTFIX-r5.1.ko.md)

배포판: **v2026.11.26-r5** / 통합본 식별자: `r4-paint-0f8b30ef8e50`

2026년 11월 26일까지 통합한 기능과 수정 사항입니다. 초기 r4a·r4b에서 이어진 내용을 포함하며, 논의만 했거나 뒤에 취소된 설계는 현재 기능으로 표시하지 않았습니다. 장면 줄거리와 대사 인용은 생략했습니다.

## 1. 한국어화와 표시

- 시나리오, 일반·전투 선택지, 스테이터스·아이템·장비, 환경 설정과 Windows 대화창을 한국어화했습니다.
- 배경 간판, 지도·적 이름·메뉴 등 이미지에 들어간 일본어를 별도 조사해 한국어 이미지로 통합했습니다.
- 초기 카탈로그의 번역 제외 9행은 r4b에서 반영했습니다. 초기 7,645개 ID는 중복 UI·루비를 포함한 후보 수로, 독립 문장 수나 모든 화면의 번역률은 아닙니다.
- 검수에서 확인한 의미 오류·용어 불일치를 고쳤습니다. 천황을 가리키는 帝, 궁중을 가리키는 禁裏 등은 게임과 영상의 용어 결정을 맞췄습니다.
- 한자의 발음을 그대로 중복하는 일반 독음 루비를 정리하고, 다른 의미·별칭·말장난·강조에 해당하는 표기는 구분했습니다.
- 한국어 본문 폭과 백로그 폭을 따로 측정해 줄바꿈을 정리했습니다. 일본어 원문의 수동 개행 때문에 한 글자·어미가 다음 줄에 홀로 남는 사례를 수정했습니다.
- 긴 글은 실제 대화창의 높이에 맞춰 페이지를 나눕니다. 전체 화면·하단 대화창·이전 장면에서 이어진 창 상태를 고려했습니다.
- 일반·전투 선택지의 글자를 선명한 흰색으로 표시하는 옵션을 기본으로 켰습니다. 원작 선택지의 그림과 강조 효과는 유지합니다.
- 저장·불러오기 목록의 대사 설명이 일본어로 깨져 보이는 문제를 수정했습니다.
- 무기마다 이름을 올바르게 표시하도록 정리했습니다. 서로 다른 무기가 같은 이름처럼 보이던 표시를 수정했습니다.

## 2. 탐색과 미니맵

- 방향키를 누르면 이동 선택지와 상단 이동 버튼을 따로 고르지 않고 곧바로 이동합니다.
- 연속 입력·길게 누르기를 다음 칸으로 이동할 수 있는 시점에 처리하며, 키를 떼면 남은 이동 입력을 취소합니다.
- 미니맵의 목적지를 클릭해 경로 이동할 수 있습니다. 문으로 표시된 칸도 직접 목적지로 선택할 수 있습니다.
- 다른 지도로 이동하는 칸과 반복 이벤트 장소는 일반 경로의 중간 통과 지점에서 피합니다. 그 장소를 직접 목적지로 선택하면 접근할 수 있습니다.
- 지도 구조와 이벤트를 실제 대본·진행 조건에 대조했습니다. 홈페이지 그림의 위치를 그대로 사용하는 방식에서 실제 게임 기준으로 보정했습니다.
- 이벤트·아이템·출구 옵션 3개를 **미니맵 마커 표시** 하나로 합쳤습니다. 새 설정의 기본값은 꺼짐이며, 끄면 원작 미니맵을 표시합니다. 기존 옵션 중 하나라도 켜져 있었다면 통합 표시로 이어받습니다.
- 현재 발동 가능한 미완료 이벤트는 녹색입니다. 선행 조건이 충족되지 않은 이벤트는 처음부터 노출하지 않습니다.
- 완료되어 다시 발생하지 않는 일회성 이벤트는 지도에서 제거합니다. 국수집·도공·반복 만남 등은 별도 반복 장소 아이콘을 사용합니다.
- 획득한 아이템 마커는 사라집니다. 획득 이력과 현재 소지 여부를 구분해 소비 뒤 다시 표시되는 문제를 줄였습니다.
- 다른 지도로 이동하는 출구는 직접 그 칸을 방문한 뒤 표시합니다. 이동이 막힌 출구는 붉은 표시로 구분합니다.
- 권장 레벨 안내와 다음 목표 표시는 별도 선택 항목입니다. 해당 구역의 할 일을 마치면 다음 목적지로 향하는 출구를 안내합니다.
- 건물·지도 진입 직후 출구 칸에서 바로 ‘나간다’가 뜨던 문제를 수정했습니다. 도착 직후는 이동 메뉴로 이어지고, 나중에 출구를 다시 밟으면 원래 나가기 질문이 나옵니다.
- 동쪽 구역 중앙의 반복 만남을 지도와 경로 회피 대상에 반영했습니다. 해당 인물을 세 번 이상 만난 뒤에는 ‘무시한다’ 선택지와 떠나는 연출을 추가했습니다.

## 3. 전투·어시스트·자동 선택

- 수동·어시스트·자동 선택을 환경 설정의 모드 탭으로 옮겼습니다.
- 추천은 단순 최대 피해가 아니라 각 결과의 피해와 성공 확률을 합친 **기대 피해**를 기준으로 합니다. 확인 가능한 확정 행동과 진행 조건을 우선 처리합니다.
- 커맨드와 검기의 피해·성공률은 **어시스트 모드 + 표시 옵션**에서만 표시합니다. 일반·자동 선택에서는 수치를 표시하지 않으며 자동 전투의 내부 계산은 유지합니다.
- 성공률은 해당 행동의 성공 가능성입니다. 전투 전체 승률이나 다음 난수의 예고가 아닙니다. 특수 조건으로 일반 계산이 성립하지 않으면 이를 구분합니다.
- 자동 선택은 행동과 전투 메시지를 진행합니다. 일반 시나리오 선택을 무차별로 대신 고르지 않습니다.
- 자동 전투 예상 승률이 50% 미만이거나 체력·공격 성공 가능성으로 패배 위험이 매우 높을 때 경고합니다.
- 경고창에서 불러오기, 계속 진행, 마지막 저장, 타이틀 이동, 이번 실행 동안 숨기기, 해당 옵션 끄기를 선택할 수 있습니다. 마지막 저장·타이틀 이동·옵션 해제에는 확인 절차를 둡니다.
- 원래 승리할 수 없는 특수 상태, 특정 장비가 필요한 전투, 퇴각해야 진행되는 전투에 각각 맞는 경고와 선택지를 연결했습니다.
- 필수 장비를 착용하고 재시작하면 실제 전투를 다시 시작하도록 수정했습니다. 재시작 선택 직후 승리 처리되던 문제를 고쳤습니다.
- 정해진 턴을 버텨야 하는 자동 전투에는 현재 진행을 보여 주는 **버티기 20턴** 안내를 추가했습니다. 원래 해제 조건과 연결해 무한 자동 전투에 빠지는 사례를 보완했습니다.
- 자동 처리 분기를 일반·특수 보스 조건으로 확장했습니다. 승리·퇴각·재시작은 원래 게임의 행동 경로를 사용합니다.
- 반드시 패배하도록 설계된 확인 대상 전투에는 경험치·주는 피해·받는 피해 배율을 적용하지 않습니다. 모든 이벤트 전투를 일괄 제외하지 않습니다.
- ‘경험치 0 일반 전투 자동 승리’는 전투 진입 후 커맨드 없이 승리 결과로 이어집니다. 고정 이벤트 전투는 이 옵션의 대상이 아닙니다.
- 패배 후 바로 타이틀로 보내던 처리를 마지막 저장 / 불러오기 / 타이틀 / 게임 종료의 네 선택지로 바꿨습니다.
- 새 전투 경고창은 기본 Windows 버튼 대신 원작 선택지의 재질·테두리·글꼴에 맞췄습니다.

자동 선택과 추천은 승리를 보장하지 않습니다. 낮은 능력치, 불리한 행동 확률, 각본 조건은 여전히 전투 결과에 영향을 줍니다.

## 4. 저장과 이어하기

- 전투 종료뿐 아니라 살아서 이벤트를 마친 뒤에도 자동 저장합니다. 사망 이벤트는 자동 저장 대상에서 제외합니다.
- 타이틀에 **이어하기**를 추가했습니다. 수동 저장·빠른 저장·이벤트/전투 후 자동 저장 중 파일의 마지막 저장 시간이 가장 최근인 것을 불러옵니다.
- 저장이 없으면 이어하기가 비활성화됩니다. 내부 임시 저장·전투 재시작용 저장은 최신 저장 선택에서 제외합니다.
- 창 종료 자체에 새 자동 저장을 만드는 기능은 추가하지 않았습니다.
- 기존 이야기 대본의 저장 위치를 보호하고, 패치 설치·업데이트·복원에서 개인 저장과 설정을 보존합니다.

## 5. 검기·장비·스테이터스

- 검기 사용과 기억하기를 계열별로 한눈에 볼 수 있는 격자로 바꿨습니다. 하위 선택지를 하나씩 열 필요가 줄었습니다.
- 원작 선택지 재질과 게임 글꼴에 맞춰 카드·테두리를 정리하고, 글자가 칸을 벗어나는 배치를 고쳤습니다.
- 미습득 기술도 최종판에서는 **기술 이름을 그대로 표시**합니다. 큰 ‘망각’ 판을 덮는 시안과 ‘사용 가능/미습득’ 반복 문구는 사용하지 않습니다. 배울 수 없는/사용할 수 없는 상태는 보드의 옅은 색과 원래 사용 조건으로 구분합니다.
- 검기 이름은 한국식 독음 / 일본어 발음 / 뜻풀이 / 모두 표기 중 하나를 선택합니다. 기술 사용·기억하기 화면의 이름 자체에 반영합니다.
- 무기 이름 풀이 옵션은 기본 꺼짐이며, 기존 장비 선택지에 마우스를 올리면 설명을 표시합니다.
- 스테이터스가 한 줄 때문에 다음 페이지로 넘어가는 문제를 정리했습니다.
- 선택형 **스테이터스·아이템·장비 통합 메뉴**로 능력치와 장비·회복 아이템을 한 화면에서 다룹니다. 전투 중 장비 교체는 제한되며 아이템 사용은 원래대로 턴을 소비합니다.

## 6. 모드 설정

| 항목 | 현재 동작 |
|---|---|
| 경험치 배율 | 1~20배, 1은 원래 경험치 |
| 주는 피해 배율 | 1~20배, 1은 원래 피해 |
| 받는 피해 감소 | 0~20단계, 매 단계 5% 감소. 0은 원래 피해, 10은 절반, 20은 0 |
| 적 조우 배율 | 0~5배. 0이면 무작위 전투 없음, 고정 이벤트 전투 유지 |
| 자동 이동 속도 | 1~20배. 이동 사이의 대기를 단축하며 장면 처리 시간은 그대로 영향을 줌 |
| 미니맵 마커 표시 | 이벤트·아이템·발견 출구 통합 표시 |
| 권장 레벨 경고 / 다음 목표 | 진행 상태와 구역 정보를 바탕으로 선택적으로 안내 |
| 불리한 전투 경고 | 자동 전투의 위험 안내와 불러오기 선택 |
| 모든 콘텐츠 개방 | 진행 기록을 조작하지 않고 감상 콘텐츠 접근 허용 |
| 확장된 기록실 콘텐츠 | 장면·음악·요약 목록 이용 |
| 검기 이름 / 무기 이름 풀이 | 이름 표기 방식과 선택형 설명 |
| 통합 메뉴 | 스테이터스·아이템·장비 한 화면 |
| 모두 끄기 / 모두 켜기 | 일괄 전환. 이전 지정 배율을 기억하고 복원 |

받는 피해 감소는 예전의 ‘피해를 배수로 나누기’ 방식에서 **5% 단위 감소**로 변경했습니다. 적용 후 소수점은 올림합니다. 자동 이동 20배는 전체 게임의 프레임·연출을 20배 가속한다는 의미가 아닙니다.

모드 항목 오른쪽에 원래 동작과 모드 적용 후를 그림과 설명으로 비교하는 칸을 추가했습니다. 선택 모드에도 별도 설명과 ‘자동 선택은 승리 보장이 아니다’라는 안내를 넣었습니다. 설정창은 마지막에 사용한 탭을 기억합니다.

## 7. 기록실

- CG 감상·장면 다시보기·음악 다시 듣기·EX 시작·하나치라스 요약을 상단 탭으로 정리했습니다.
- CG 감상은 썸네일과 읽을 수 있는 제목으로 선택합니다. CG를 클릭하면 차분까지 감상할 수 있습니다.
- 장면 다시보기 38개를 구역별 왼쪽 목록과 4열×3행 카드로 배치했습니다. 내부 함수명 대신 장면 제목을 사용합니다.
- 음악 26곡에 확인한 공식 OST 제목을 붙이고 관련 이벤트 CG를 배치했습니다. 추가곡 가운데 공식 제목을 확인하지 못한 것은 확인되지 않은 이름을 만들어 넣지 않았습니다.
- 사용자가 선택 저장한 **음악 7개·요약 2개, 총 9개 CG**를 반영했습니다.
- 음악 목록의 휠은 한 번에 이전·다음 곡으로 이동합니다. 상단 탭 위 휠은 분류 전환, 장면 목록 휠은 구역 전환에 사용합니다.
- 기록실에서 우클릭하면 이전 메뉴로 돌아갑니다.
- 확인된 보컬곡의 일본어·한국어 가사 자막을 화면 하단에 함께 표시합니다. 타이틀에서 흐르는 짧은 보컬 버전에도 해당 자막을 연결했습니다.
- 사용자 제공 하나치라스 요약은 11항목으로 통합하고, 사실관계 검수·대표 CG·순차 재생을 연결했습니다. 이는 원작 추가 시나리오 원문을 복원한 것이 아닙니다.
- 장면 다시보기 진입 시 이전 장면 배경이 잠깐 비치던 문제와 CG 전환 중 빈 프레임이 드러나는 문제를 수정했습니다.

## 8. 오프닝과 창·입력

- 화면 문구·게임 선택지·주요 로고를 한국어화한 프로모션 영상을 만들고 게임 오프닝으로 통합했습니다.
- 첫 실행에는 니트로 로고 대신 오프닝을 한 번 재생합니다. ‘게임 실행 시 PV 재생’은 기본 꺼짐이며, 켜면 다음 실행부터 반복 재생합니다.
- 첫 재생에서만 ESC에 스킵 확인을 띄웁니다. 반복 재생의 ESC는 바로 건너뛰며, 마우스 클릭으로는 스킵 질문이 나오지 않습니다.
- 일반 이펙트 영상에는 PV 전용 확인창이 개입하지 않도록 분리했습니다.
- 니트로 로고·시작 경고를 건너뛰는 옵션은 PV 재생 여부와 독립적입니다.
- 원문 로고 아래 한국어 병기 / 한국어화 로고 중 선택할 수 있습니다.
- 마지막 로고를 더 오래 유지하고, 해당 타이틀 화면과 이어지도록 위치·종료 처리를 맞췄습니다.
- 창 크기를 자유롭게 조절하고 화면 비율·입력 좌표를 연결하도록 개선했습니다.
- 불러오기·저장·확인창을 닫은 뒤 본창에 입력이 돌아오지 않는 NitroSystem 스레드 입력 큐 문제를 수정했습니다.
- 한국어 Windows와 한글 경로에서 Locale Emulator 없이 실행되도록 엔진의 코드 페이지 처리를 맞췄습니다.

## 9. 이번 배포 직전의 마지막 수정

- 메인 타이틀이 먼저 보인 뒤 오프닝이 뒤늦게 시작되던 순서를 고쳤습니다. 영상 준비 중에는 검은 화면을 유지하고 타이틀은 영상 뒤에 표시합니다.
- 음악 휠 전환 시 목록이 하얗게 번쩍이던 창 지우기·배치 갱신을 수정했습니다.
- 기록실을 처음 열 때부터 현재 탭·구역이 강조되게 했습니다.
- 탭·구역을 바꾸면 이전 밑줄과 색이 지워지고, 현재 선택 하나만 강조되게 했습니다. 키보드 포커스와 선택된 항목도 구분했습니다.

## 10. 배포·검증과 남은 범위

원본 7개 파일 차분과 새 한국어 런타임을 묶었습니다. 새 설치, r4a·r4b 업그레이드, 반복 설치, 검사, 원본 복원과 저장·설정 보존을 별도 시험 사본에서 확인합니다. 최신 설치 결과는 기존 네이티브 검증을 거친 통합본과 SHA-256으로 대조합니다.

본문 정적 검사 범위는 68개 대본·8,740개 표시 행입니다. 변경된 기능의 실제 엔진 검증과 이전에 통과한 동일 구성 요소의 증거를 구분해 보관했습니다. 모든 분기를 다시 완주했다거나 모든 동적 화면을 보았다는 뜻은 아닙니다.

남은 제한은 [검증 범위](STATUS.md)에 모았습니다. 전체 시나리오 완주 검수, 모든 저장 지점의 호환성, 추가곡 일부의 공식 제목 확인, 게임 내 문장 검색·직접 편집 도구는 완료 범위에 넣지 않았습니다.
