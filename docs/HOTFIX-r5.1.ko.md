# 계엄성도 r5.1 소형 업데이트

r5 통합 패치에 다음 두 수정만 추가합니다. **r5가 설치된 게임용**이며 처음 설치할 때는 r5 통합본을 먼저 설치하세요.

- **도쿄 부지사 자동 항복:** 항복해야 진행되는 조건에서 자동 선택이 기존 항복 분기로 이어집니다. 조건 밖이나 수동·어시스트 모드에서는 자동 항복하지 않습니다.
- **창 크기 조절:** 원본 엔진이 Windows의 크기 조정·최대화 명령을 지우던 처리를 막았습니다. 실제 테두리 드래그, 최대화·복원, 크기 기억과 조절된 화면의 마우스 입력을 확인했습니다.

`Install.cmd` 실행 → r5 게임 폴더 선택으로 적용합니다. `ko.dll` 하나만 업데이트하며 **대본·SAVE·설정·영상·그래픽은 변경하지 않습니다.** 전체 패치와 PV를 다시 받을 필요가 없습니다. `RestoreHotfix.cmd`로 r5로 되돌릴 수 있습니다.

부지사 비교·조건 검사 7건, 실제 창 조작 및 재실행, 설치·복원·오류 거부 9건을 확인했습니다. 전체 분기 재완주 검수를 뜻하지 않으며 기존 통합본과 같이 Pre-release로 배포합니다.
