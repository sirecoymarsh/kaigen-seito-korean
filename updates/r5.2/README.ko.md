# 계엄성도 r5.2 소형 업데이트

r5.1 설치본에 적용하는 ko.dll 차분 업데이트입니다. 처음 설치하면 r5 통합 패치 → r5.1 → r5.2 순서로 적용하세요.

- 오프닝이 검은 화면과 소리만 나오는 문제: 기존 DirectShow의 파일 읽기·디코딩·음성·종료 처리를 유지하고, 해당 게임의 영상 출력 장치만 소프트웨어 표시 방식으로 지정했습니다. 시스템 전체 코덱 설정은 바꾸지 않습니다.
- 창 크기를 변경한 상태에서 전투 직후 미니맵 표시가 빠지는 문제: 800×600 논리 좌표를 실제 창 좌표로 변환해 다시 그립니다. 경로·마커·범례의 갱신 8곳에 적용합니다.
- 큰 창에서 타이틀 가사 자막이 잘리는 문제: 글자 확대율에 맞춰 클리핑 영역도 변환합니다.

## 설치와 복원

1. 게임을 종료하고 ZIP을 별도 폴더에 풉니다.
2. Install.cmd를 실행하여 r5.1이 설치된 게임 폴더를 선택합니다.
3. Verify.cmd로 검사할 수 있습니다.

ko.dll 하나만 바꿉니다. SAVE·설정·대본·영상·그래픽·기존 백업은 변경하지 않습니다. RestoreHotfix.cmd는 r5.1 DLL로 복구합니다. 복원용 백업은 .kaigen-ko-r5.2-backup에 보존됩니다. 그 이전으로 복원하려면 각 버전의 복원을 역순으로 실행하세요.

## 검증 범위

실제 엔진에서 오프닝 전체 재생과 타이틀 복귀, 첫 ESC 확인·마우스 무시·타이틀 입력, 640×480/800×600/1000×750/1600×1200 영상 영역을 확인했습니다. 전투 승리 직후 이동하지 않은 미니맵의 갱신 영역, 축소·확대 화면의 클릭 경로와 방향키, 최대화·복원, 자막·생존 HUD·독립 설정창을 검사했습니다. 출력 관련 네이티브 호출과 추가 UI 좌표 경로를 함께 검토했습니다.

전체 이야기 재완주나 프레임 드롭·지터 측정을 새로 수행했다는 뜻은 아닙니다. 상세 범위는 verification.json에 있습니다.

차분 도구는 HDiffPatch 5.1.3이며 라이선스는 LICENSES에 있습니다. 후속 한국어 문구 작성: Codex internal.
