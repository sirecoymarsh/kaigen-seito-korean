# 계엄성도 r5.1 소형 업데이트

r5(v2026.11.26-r5)가 설치된 게임에 두 수정만 적용합니다. 처음 설치한다면 먼저 r5 통합 패치를 설치하세요.

- 자동 선택에서 도쿄 부지사에게 항복해야 진행되는 조건을 만났을 때, 기존 ‘항복한다’ 분기로 이어집니다. 그 조건 밖이나 수동·어시스트 모드에서는 자동 항복하지 않습니다.
- 원본 엔진이 지우던 Windows의 크기 조정·최대화 명령을 보존하여, 창 테두리 드래그와 최대화 버튼이 작동합니다. 4:3 비율과 크기 기억은 유지합니다.

## 설치

1. 게임을 종료합니다.
2. 이 ZIP을 별도 폴더에 풉니다.
3. `Install.cmd`를 실행하고 r5가 설치된 게임 폴더를 선택합니다.
4. `Verify.cmd`로 검사할 수 있습니다.

변경 파일은 `ko.dll` 하나입니다. DLL 전체 대신 변경분만 들어 있어 영상과 대형 PAK을 다시 받을 필요가 없습니다. SAVE, 설정, 대본, 그래픽, 영상, 원본 백업은 수정하지 않습니다. 설치 중 약 150MB의 여유 공간이 필요합니다.

## 핫픽스 제거

`RestoreHotfix.cmd`는 업데이트 전 r5 DLL로 되돌립니다. 백업은 게임 폴더의 `.kaigen-ko-r5.1-backup`에 보존됩니다. 원본 일본어판까지 되돌리려면 핫픽스를 제거한 뒤 r5 통합 패치의 `Restore.cmd`를 사용하세요. 기존 `.kaigen-ko-backup`은 지우지 마세요.

r5 이외의 판이나 알 수 없는 수정본에는 적용하지 않습니다. 파일 해시 확인 후 차분을 생성하고 원자적으로 교체합니다. 설치 중 게임을 새로 실행하지 마세요. 정전·강제 종료 뒤 잠금 파일이 남으면 설치기가 종료됐는지 확인한 후 게임 폴더의 `.kaigen-ko-install.lock`을 제거하고 다시 실행할 수 있습니다.

## 검증 및 도구

부지사 조건·방문 횟수·수동/어시스트 구분 7건, 실제 Windows 테두리 드래그·최대화·복원, 창 크기 재실행 기억과 조절된 화면의 마우스 불러오기를 검증했습니다. 전체 분기 재완주를 뜻하지는 않습니다.

차분 도구: [HDiffPatch 5.1.3](https://github.com/sisong/HDiffPatch/releases/tag/v5.1.3). 동봉 라이선스는 LICENSES 폴더에 있습니다. 기존 엔진과 기존 패치의 런타임을 재사용했습니다. 후속 한국어 문구 작성: Codex internal.
